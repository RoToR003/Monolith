Ліцензія й авторство

База — Telegram Web K, автор Eduard Kuzmenko та співавтори. Збережено GPL-3.0-only й авторські повідомлення upstream. Окремі компоненти мають власні ліцензії, наведені у відповідних каталогах вихідного коду.

Локальні зміни Monolith та скрипти збірки доступні за посиланням вище. Вихідний код можна переглядати й клонувати без оплати; окремі архіви на цьому сайті не розміщуються. Програма поширюється БЕЗ БУДЬ-ЯКОЇ ГАРАНТІЇ, у межах, дозволених законом.

git clone --branch monolith/baseline https://github.com/RoToR003/Monolith.git
cd Monolith
git checkout f39177904820e425187da9f092a3ac8fc5deb35e
bash scripts/monolith.sh setup
bash scripts/monolith-pages.sh build

Перед входом

  • GitHub Pages роздає статичні файли. Клієнт з’єднується з Telegram із вашого браузера; окремого сервера Monolith для сесій немає.
  • Ця тестова збірка використовує опубліковані upstream development API-реквізити. Перед власним повноцінним розгортанням зареєструйте застосунок на my.telegram.org/apps.
  • Авторизація користувача, чати після входу, дзвінки, push, реальний iPhone/Safari та встановлення PWA ще не пройшли повну перевірку. Ghost Mode, Anti-Recall та інші розширення Monolith не реалізовані.
  • Не передавайте нікому коди входу, 2FA-пароль чи файли сесії. Шляхи одного домену GitHub Pages не є ізольованими сховищами; не розміщуйте сторонній неперевірений код на цьому ж origin.
